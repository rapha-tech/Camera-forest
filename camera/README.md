# Use case of the camera

The camera will take pictures of the trees which will be a few hundred meters away.
It must save the images locally for backup purposes. 


# functional analysis

| ID  | Function                       | Criteria                 | Level            | Tolerance |
| --- | ------------------------------ | ------------------------ | ---------------- | --------- |
| FC1 | Capture images of the trees    | Resolution               | 1 pixel = 1 cm²  | 10%       |
|     |                                | Frequency                | 2 pictures / day | 0%        |
|     |                                | Distance                 | 500m             | ?         |
| FC2 | Save the images locally        | Quantity of images saved | 2x30x3           | 0%        |
