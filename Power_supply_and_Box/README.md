## POWER SUPPLY AND CASING

this section describes the power supply and the case used in the project. 
The power supply is responsible for providing the necessary voltage and current to the components of the system, 
while the box serves as a protective enclosure for the electronics.


# Use case for Power Supply #

The system is powered by a battery.

The power supply is capable of : 
* Sustaining the system for 3 mounth minimum
* Power each component of the system
* fit in a small box 

# Functional analysis for power supply 

the system needs to respect each function quoted below :

1) Being autonomous for 3 mounths
2) give enough power to supply each component
3) store energy


# Use case for the case

The case will hold the entirety of the system inside

the casing is capable of : 
* To proctect the system
* to resist to rain and windstorm
* to seal the system from humidity and hot tempeture

# Functional analysis for power supply 

the system needs to respect each function quoted below :

1) Being in norm IP65
2) resisting to raining and windstorm
3) sealing the system from humidity
4) resisting to any damage done on the casing
